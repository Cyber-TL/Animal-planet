# Huellitas - Sistema web de adopción canina

Proyecto SENA ADSO - CBA Mosquera.

## Estructura

- `frontend/` React + Vite (SPA)
- `backend/` API (pendiente)
- `database/` scripts MySQL (schema.sql, seed.sql)
- `docs/` documentación del proyecto

## Correr el frontend

    cd frontend
    npm install
    npm run dev
